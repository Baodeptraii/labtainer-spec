# Changelog

## 1.0.0

- Public distribution with a coordinator and ten individually invocable step skills.
- Preserve detailed step procedures and checklists; parameterize personal connection and filesystem values.
- Shared report renderer, academy DOCX template, HTML template and VM helpers.
- Local run configuration with password references through environment variables.
- Project installer, release validation, offline tests and GitHub Actions CI.
- MIT license for code/instructions, separate institutional asset notice and contributor credits.

This release validates packaging and helper behavior offline. It does not certify
that every lab works or that remote GUI automation is available on every host.
